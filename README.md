# GPA Calculator — Radiology

حاسبة المعدل التراكمي لقسم تقنيات الأشعة، مبنية باستخدام React وVite.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## النشر على GitHub Pages

المشروع يحتوي مسبقاً على GitHub Actions داخل:
`.github/workflows/deploy.yml`

بعد رفع المشروع إلى Repository باسم `gpa-calculator` على GitHub:
1. افتح Settings → Pages.
2. اجعل Source = GitHub Actions.
3. ادفع أي تحديث إلى فرع `main`.
4. سيُنشر الموقع تلقائياً.

الرابط النهائي:
`https://USERNAME.github.io/gpa-calculator/`
